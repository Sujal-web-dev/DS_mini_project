# Student Record Management System

Data Structures mini-project: a menu-driven C program that manages student
records (registration number, name, marks) using a **singly linked list**.

## Files
- `student_record.c` – the C program (add, search, delete, display, exit)
- `index.html` – web version of the project (dashboard, linked-list view, documentation, Excel export)

## Run the C program
```
gcc student_record.c -o student_record
./student_record
```

## Web version
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`).
